# Weave Office 早期集成实验

正式入口已移到仓库根目录，当前宿主位于 `src/host.rs`，应用界面位于 `src/app.rs`。本目录保留作早期方案参考，不作为交付入口。产品目标与验收标准见 [规划文档](../PLAN.md)。

本目录包含两个独立部分：

- `src/lib.rs` 是统一引擎宿主，当前可在同一工作区创建、打开和关闭文字、表格、演示及 PDF；同一路径重复打开时复用已有标签；支持 DOCX、XLSX、PPTX、PDF 的同步另存为，以及通过 PdfCraft 引擎执行 PDF 编辑命令。未完成所有格式、加密文件和复杂文件的兼容性验证。
- `src/main.rs` 是早期的三编辑器同窗验证程序。它仍保留各自的界面及部分文件和窗口行为，**没有接入上面的统一宿主，也不支持 PDF**。它不是目标中的统一文件标签栏，字体、主题和退出保护仍需处理，不应用于重要文档。

需要 Rust 1.95.0，依赖路径已指向仓库内的 `vendor/`。源码来源、提交版本及许可证见 [上游记录](../vendor/README.md)。

运行统一引擎宿主测试：

```sh
cargo +1.95.0 test --manifest-path integration/Cargo.toml --lib
```

已验证四种原生格式的空白文档新建、保存和重新打开，以及 PDF 重复打开和未保存关闭保护。复杂文件保真、加密和图形界面尚未验证。不要在原始文件上测试此实验。
