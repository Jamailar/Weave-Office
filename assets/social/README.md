# Social preview

`social-preview.png`(1280×640)是 GitHub 仓库的 social preview 图,也用在 README 顶部。

它由同目录的 `social-preview.html` 渲染:用 Chromium 打开(视口 1280×640),等字体加载完后截图即可重新生成。图里的窗口和终端是示意,不是实际截图;应用图标取自 [`../app-icon/weave-office.png`](../app-icon/README.md)。

GitHub 不会从仓库读取这张图:需要在仓库 Settings → General → Social preview 里手动上传。
