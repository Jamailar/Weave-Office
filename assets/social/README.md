# Social preview

`social-preview.en.png` and `social-preview.zh-CN.png` (1280×640) are the README banners; the English one is also the GitHub social preview.

Both are rendered from `social-preview.html`: open it in Chromium at a 1280×640 viewport with `?lang=en` or `?lang=zh-CN`, wait for fonts to load, and take a screenshot. The window and terminal are illustrations, not screenshots. The app icon comes from [`../app-icon/weave-office.png`](../app-icon/README.md). To add a language, add an entry to the `T` table in the HTML.

GitHub does not read the social preview from the repository: upload `social-preview.en.png` under Settings → General → Social preview.
