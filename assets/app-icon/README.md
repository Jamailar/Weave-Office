# Weave Office app icon

`weave-office.png` is the original imagegen concept D selected by the project owner on 2026-11-02. It evolves this project’s original four-color folded-paper and white W artwork. No third-party brand artwork or fonts were used.

Prompt: compact, refined four-color folded document panels, blue/emerald/orange/coral, bold white W, pale macOS rounded-square tile, restrained gradients and simple geometry.

The macOS icon generator sizes this approved master directly and clips the outer tile for transparent corners. Document icons keep their existing code-drawn artwork.

For Windows, `scripts/generate_windows_icon.py` crops the same master to its rounded tile with transparent corners and writes `weave-office.ico` (16–256 px, embedded in `weave-office.exe` and used by the installer) and `weave-office-256.png` (the window and taskbar icon on Windows and Linux).
