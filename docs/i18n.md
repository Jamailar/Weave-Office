# 统一界面语言与翻译输入

Weave Office 的公共设置支持简体中文（默认）与 English。这是四个当前编辑器可提供的界面语言交集；不以某一个编辑器的较长语言列表承诺全应用支持。宿主的 `settings.language` 是唯一持久化来源，旧设置文件继续默认简体中文；已打开、新建及后台生成的文档都接收同一偏好，切换标签不恢复独立语言。编辑器的翻译目录负责专业功能名称。

WordCraft 的中文目录是单独的编译输入。缺少目录时，上游会仅嵌入英文，设置 `zh-hans` 也不能显示中文。因此构建使用 `vendor/wordcraft/craft-i18n.rev` 指定的官方 [craft-i18n](https://github.com/storytold/craft-i18n) 固定版本，下载到外置盘：

```sh
python3 scripts/prepare-i18n.py
python3 scripts/prepare-i18n.py --verify-only
```

目录为 `/Volumes/Jamba/DevCache/WeaveOffice/inputs/craft-i18n`。脚本验证提交号、干净工作树、许可文件和两份简体中文 TSV 目录；不会静默切换已有输入的版本。构建时设置绝对路径 `CRAFT_I18N_DIR` 及 `CRAFT_I18N_REQUIRED=1`，目录编译进应用，运行时不需要外置盘。

GridCraft 与 PdfCraft 使用各自现有的内嵌翻译。DeckCraft 已加入宿主控制的公共标签翻译，主功能区、状态栏与备注批注入口支持中文；高级对话框和渲染引擎生成的占位提示仍需继续覆盖。用户正文、文件名、已有样式名和语言元数据不自动翻译。

打包保留 craft-i18n 的 MIT、Apache-2.0 许可与贡献者归属。源目录与嵌入方式见[上游说明](https://github.com/storytold/craft-i18n/blob/9205108cfdced5177706264038848b68b2422d2b/docs/integration.md)。

## 入口与文档语言边界

- 文件菜单的设置、各引擎的应用偏好进入同一设置窗口。Word 审阅中的 Language Preferences 保留 `file.options {pane:"language"}`，定位语言页；不改成 `review.language`，不隐藏入口。未知设置页会明确返回未接入操作。
- 语言页提供公共界面语言，以及当前 Word 光标处的原只读校对状态。文档校对语言仍由原 Set Proofing Language / Set As Default 工作流修改，完整专业语言列表保留。切换显示语言不会改变空白或已有 Word 的语言元数据、正文、undo 或 dirty。
- Word `ui.language` 和 Grid `app.language.set` 在 hosted 边界交给公共壳；Grid 原界面语言选择器仅展示公共支持的简中和 English。其它显示语言请求明确不支持，不悄悄降级。
- 应用公共导航、文件菜单、新建、设置、确认、错误标题、打印及应用提供的原生文件面板菜单使用同一显示语言。诊断正文可保留引擎原文。操作系统自己的原生面板控件与 traffic lights 仍由系统管理。

## 字体与验证

非活动文档只接收语言字段，不运行编辑逻辑、不安装字体。激活时仍按原输入时序恢复文档 Memory / fonts，再运行引擎的语言相关字体准备；PDF hosted 路径也检查 CJK 优先顺序变化。未引入每文档的持久化语言或每帧清空字体。

`python3 scripts/cargo.py test --locked --offline -j3 -p weave-office --lib shared_language -- --test-threads=1` 覆盖旧偏好迁移/序列化、原语言页命令及可见英文控件、双向语言切换后的四引擎真实绘制与标签往返、Word 校对及内容不变、新建和生成 PDF 继承，以及 PDF 字体族顺序。翻译覆盖有限的专业界面仍按上游回退英文；这些测试不代表每个专业对话框已完成翻译。
